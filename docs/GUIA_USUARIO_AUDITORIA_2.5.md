# Guía de usuario - Auditoría de ventas 2.5

Ruta: **Ventas → Sincronizaciones → Auditoría de ventas**.

Botones principales:

- **Auditar mes**: compara totales Mercado Libre vs ERP sin descargar detalles.
- **Comparar IDs del mes**: lista IDs faltantes de forma liviana.
- **Diagnosticar fechas**: revisa muestras cercanas a cortes horarios.
- **Recalcular fechas**: crea trabajo para recalcular fechas desde datos ya guardados.
- **Corregir mes auditado**: crea trabajo para traer solo órdenes faltantes.

Si aparece “posible desplazamiento horario”, use primero **Recalcular fechas** y luego repita la auditoría.
